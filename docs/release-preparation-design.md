# Подготовка Astra MWE v0.1.0 к релизу

Дата: 2026-09-18

## Цель

Подготовить текущее состояние Astra MWE как первый обычный выпуск `v0.1.0`, убрать экспериментальную маркировку POC и локальные артефакты, привести публичную документацию и метаданные к единому виду, проверить проект и перенести проверенные коммиты в существующую ветку `Main`.

## Границы работы

- Версия продукта во всех публичных текстах, метаданных Windows и именах архивов — `0.1.0`; Git-тег выпуска, если понадобится, будет создан отдельно после успешного CI в `Main`.
- Тёмное оформление остаётся обязательным свойством интерфейса.
- Поддерживаемые цели сборки: Windows x64, Windows ARM64, Linux x64 и Linux ARM64. Успешная сборка не считается подтверждением работоспособности: README и журнал проверок должны отдельно называть реально проверенные среды.
- Формат экспорта, чтение миров без записи и существующие пользовательские сценарии не меняются.
- Minecraft, миры, клиентские JAR, моды, ресурспаки, скины и пользовательские пути не включаются в репозиторий или архивы.

## Очистка

Из рабочей копии удаляются игнорируемые локальные кэши, установленные зависимости, сгенерированный фронтенд, бинарники, тестовые исполняемые файлы, архивы и временные ресурсы Windows. Исходная иллюстрация `build/assets/astra-mwe.jpg` и необходимые исходники иконок сохраняются.

Из набора файлов выпуска удаляются дублирующие корневые сценарии `build-all.cmd` и `build-all.sh`: каноническими остаются `scripts/build.ps1` и `scripts/build-linux.sh`. Внутренние исторические спецификации и планы из `docs/superpowers/` не входят в итоговое состояние репозитория. Эта утверждённая спецификация также удаляется завершающим коммитом очистки, но остаётся в истории Git как обоснование изменений.

## Документация и метаданные

Основной `README.md` остаётся русским, `README.en.md` — английским. Оба описывают продукт, быстрый старт, возможности, ограничения, сборку, проверку и лицензирование без слов `poc` или `proof of concept`. Ограничения формулируются как состояние версии `0.1.0`, без заявления о полной готовности или неподтверждённой совместимости.

Маркировка POC удаляется из:

- заголовков окон, HTML и встроенной справки;
- сведений о версии и описаний Windows EXE;
- имен и тестов архивов выпуска;
- CI, changelog, журнала проверок и руководства участника;
- любых иных отслеживаемых исходных и текстовых файлов.

`CHANGELOG.md` содержит один раздел `0.1.0` с актуальным описанием первого выпуска вместо отдельных подготовительных и POC-разделов. README не должен ссылаться на сгенерированный файл, отсутствующий в чистом клоне.

## Репозиторий и выпуск

`.gitignore` должен исключать только воспроизводимые сборочные результаты, зависимости, кэши, логи и пользовательские данные, не скрывая обязательные исходники. CI продолжает тестировать четыре целевые комбинации ОС и архитектуры и упаковывает архивы с версией `0.1.0`.

Изменения фиксируются содержательными коммитами в `codex/wails-webgl-exporter`. После полной локальной проверки существующая ветка `Main` переводится на результат только fast-forward с помощью `git merge --ff-only`; переписывание истории не используется. Удалённый репозиторий сейчас не настроен, поэтому push и публикация релиза в эту работу не входят.

## Проверка

Перед переносом в `Main` выполняются:

1. поиск оставшихся упоминаний `poc` и `proof of concept` вне истории Git и зависимостей;
2. `gofmt` и проверка чистоты форматирования Go;
3. `go test ./...` и `go vet ./...`;
4. `npm run format:check`, `npm test` и `npm run build` в `frontend/`;
5. доступные на текущей Windows-машине сборки Windows x64 и ARM64;
6. тест упаковщика и проверка имен архивов `0.1.0`;
7. проверка ссылок и состава файлов README, `git status` и итогового diff.

Linux-сборки и запуск ARM64 не объявляются проверенными локально, если они фактически не выполнялись. Их сборку должен подтвердить CI на соответствующих runners.

## Критерии готовности

- В отслеживаемых файлах нет маркировки POC.
- Публичные тексты и метаданные используют версию `0.1.0`.
- Чистый клон содержит все исходники и инструкции, необходимые для тестов и сборки.
- Репозиторий не содержит локальных миров, зависимостей, кэшей, бинарников или архивов сборки.
- Все доступные локальные проверки завершились успешно либо их точные ограничения зафиксированы без завышенных заявлений.
- `Main` указывает на проверенный итоговый коммит, а рабочая копия чиста.
