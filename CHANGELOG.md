# История изменений

## 0.1.0 — 2026-09-18

Первый выпуск Astra MWE.

- Экспорт выбранных областей Minecraft Java 1.13+ в GLB с отдельными материалами, исходными именами текстур и объектами игроков.
- Чтение миров и ресурсов установленных лаунчеров, ресурспаков и JSON-ресурсов модов без выполнения Java-кода модов.
- Тёмный интерфейс на Wails, 2D-карта и WebGL2-просмотр с навигацией в стиле Blender.
- Параллельная подготовка участков, фоновый разбор GLB, группировка вызовов отрисовки и потоковая запись больших экспортов.
- Автоматическая высота, смешивание цветов биомов, опциональная полая листва и оптимизация меша.
- Воспроизводимые сборки и архивы для Windows x64, Windows ARM64, Linux x64 и Linux ARM64 с SHA-256.
- MIT для кода проекта, отдельные уведомления о лицензиях зависимостей и документация на русском и английском.
- Исправлена безопасная упаковка: неудачная операция не заменяет предыдущий корректный архив.

Локально проверен браузерный режим Windows x64. Сборки Linux и ARM64 предусмотрены, но их успешная сборка сама по себе не подтверждает работоспособность среды выполнения. Подробности и текущие ограничения приведены в README и `docs/verification.md`.

Миры, клиентские JAR, моды, ресурспаки, скины, кэши и локальные тестовые данные в архивы выпуска не включаются.
