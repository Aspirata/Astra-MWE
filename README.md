# Astra MWE

<img src="frontend/public/icon.png" width="128" alt="Astra MWE" />

**Minecraft World Exporter · v0.1.0 · [English](README.en.md)**

**Astra MWE — не готовый экспортёр, а proof of concept.** Проект исследует экспорт миров Minecraft Java 1.13+ в GLB как альтернативу рабочим процессам на основе OBJ и USD. Версия 0.1.0 предназначена для практических экспериментов и может содержать ошибки геометрии, неполную поддержку модов и ограничения производительности на сложных мирах. Совместимость со всеми версиями и ресурспаками не гарантируется.

Программа полностью создана с помощью ChatGPT на модели **GPT-6 Astra** с уровнем рассуждений **high**.

Ядро — Go, настольное окно — Wails, просмотр — Three.js/WebGL2. Мир открывается только для чтения. Minecraft, клиентские JAR, моды, ресурспаки и скины не включены в поставку.

## Запуск и экспорт

Распакуйте архив своей платформы. В Windows запустите `astra-mwe-windows-amd64.exe` (x64) или `astra-mwe-windows-arm64.exe`. Нужен Microsoft Edge WebView2 Runtime. Linux GUI требует GTK3 и WebKitGTK 4.1. CLI работает без WebView и GPU.

1. Выберите найденный мир либо его папку / `level.dat`.
2. Выберите клиентский `.jar` той же версии Minecraft. Найденное точное совпадение подставляется автоматически.
3. Добавьте JAR модов и ZIP / папки ресурспаков. Ниже в списке — выше приоритет.
4. В виде «Сверху» выделите область мышью или введите координаты справа. Высота и меш пересчитываются автоматически. Запас вниз — минимум четыре блока; диапазон Y можно задать вручную.
5. При необходимости включите «Оптимизировать меш». Выберите новое имя `.glb` и экспортируйте.
6. В Blender откройте File → Import → glTF 2.0. Для дробной прозрачности используйте Dithered в настройках материалов.

Существующие файлы не перезаписываются. GLB содержит отдельные текстуры с исходными именами, материалы блоков и один объект геометрии мира; игроки — отдельные объекты. Атлас текстур не создаётся. Dithered — настройка Blender, а не режим glTF; файл сохраняет дробную альфу.

## Возможности

- Тёмный интерфейс: импорт слева, экспорт справа, справка — F1. Настройки действуют в текущем сеансе; ручного сохранения профиля нет.
- 2D-карта загружается по границам окна. При приближении видны настоящие пиксели текстур, сверху — лица игроков.
- 3D показывает окружение с запасом **128 блоков (8 чанков) с каждой стороны**. Для огромных выделений основа просмотра ограничена центральными 256×256 блоками. Ближайшие участки загружаются первыми; бюджет памяти может ограничить дальнюю часть. Это не ограничивает экспорт.
- Параллельная подготовка участков Go и разбор GLB в фоновых потоках браузера. Меш просмотра всегда оптимизируется.
- Цвета биомов всегда включены со смешиванием на семь блоков. Вишнёвая листва сохраняет свой цвет.
- JSON-модели, blockstates, multipart, наследование, UV и ресурсы модов из выбранных архивов. Java-код модов не исполняется.
- Сохранённые позиции игроков, переход к игроку и скины через NameMC с резервным Mojang. Если источники недоступны и скина нет в кеше — Стив. Флаг экспорта игроков не скрывает их в просмотре.
- Полая листва по умолчанию выключена. Оптимизация экспорта объединяет совместимые грани с сохранением текстур и оттенков; без неё блоки сохраняют отдельные грани.

## Управление

| Действие | Управление |
|---|---|
| Орбита | СКМ |
| Сдвиг | Shift + СКМ; сверху — СКМ |
| Масштаб / плавный dolly | Колесо / Ctrl + СКМ |
| Выделение сверху | ЛКМ с перетаскиванием |
| Показать выделение | F или Num. |
| Спереди / справа / сверху | Num1 / Num3 / Num7; Ctrl — обратная сторона |
| Перспектива / ортография | Num5 |
| Полёт | Shift + ~, мышь, WASD, Q/E; Shift ускоряет, Esc завершает |

Оси справа снизу кликабельны. Y — высота Minecraft.

## Текущие ограничения

- Лимита площади выделения нет, но большие экспорты требуют времени и места для временных файлов. Один GLB ограничен примерно 4 GiB самим форматом. При сборке частями грани объединяются внутри участков.
- Специальные рендереры блоков, waterlogged-геометрия, все частичные препятствия для жидкостей, CTM/CIT, шейдеры, PBR, анимация текстур и обычные сущности поддерживаются не полностью либо не реализованы. Неизвестные модели могут заменяться заметными кубами с сообщением.
- Шум болотных оттенков и точные границы биомов воспроизводятся не полностью. Автовысота ориентируется на твёрдую поверхность, включая крыши. Позиции игроков берутся из сохранения, не из онлайн-сессии.
- Скорость зависит от мира, ресурсов, диска, WebView и видеокарты. Замеры не гарантируют FPS на другой сцене.
- Локально проверен браузерный режим Windows x64. Linux GUI и запуск ARM64 **не проверены**; сборка не означает подтверждённую совместимость. [Журнал проверок](docs/verification.md) содержит условия измерений.

## Сборка

Устройство исходников, правила комментариев и владения ресурсами описаны в [CONTRIBUTING.md](CONTRIBUTING.md).

Нужны Go 1.25+, Node.js 24 и npm. Зависимости закреплены в `go.mod` и `frontend/package-lock.json`.

Windows PowerShell:

```powershell
./scripts/build.ps1 -Architecture amd64
./scripts/build.ps1 -Architecture arm64
```

Linux (например Ubuntu 24.04; собирать на соответствующей архитектуре):

```sh
sudo apt install build-essential pkg-config libgtk-3-dev libwebkit2gtk-4.1-dev
bash scripts/build-linux.sh amd64
# На ARM64: bash scripts/build-linux.sh arm64
```

Скрипты создают иконки из `build/assets/astra-mwe.jpg`, затем GUI и CLI в `build/bin/`. Для прямой сборки Go сначала выполните `go run ./cmd/package-icon` и сборку фронтенда. Windows-ресурсы генерируются для x64 и ARM64.

Архив выпуска и SHA-256: `go run ./cmd/package-release -os windows -arch amd64`. Для Linux замените `windows` на `linux`; ключ `-cli-only` упаковывает только CLI. Результат — `build/releases/`. Перед упаковкой соберите исполняемые файлы нужной платформы.

Проверки: `go test ./...`, `go vet ./...`, затем в `frontend/` — `npm test` и `npm run build`. Для разработки интерфейса: `go run -tags desktop,production . --serve 127.0.0.1:34115`. Локальный сервер заменяет системные диалоги вводом путей.

CLI (имя исполняемого файла зависит от платформы):

```sh
astra-cli -discover
astra-cli -world /path/to/world/level.dat -inspect
astra-cli -world /path/to/world -resource /path/to/client.jar -min-x 0 -max-x 31 -min-z 0 -max-z 31 -max-y 180 -out area.glb
```
