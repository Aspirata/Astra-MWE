# Работа с кодом Astra MWE

Проект распространяется под MIT. Изменения должны сохранять чтение миров без записи, отдельные текстуры и воспроизводимый экспорт. Не добавляйте клиентские JAR, миры, скины или локальные пути пользователей в тестовые данные репозитория.

## Карта исходников

| Каталог / файл | Ответственность |
|---|---|
| `internal/nbt`, `internal/world` | Проверка NBT, Anvil-регионы, палитры, сохранённые игроки |
| `internal/assets` | Приоритет ресурсов, JSON-модели, текстуры и биомы |
| `internal/mesher` | Геометрия блоков/жидкостей, отсечение граней, UV, окраска |
| `internal/meshopt` | Объединение совместимых граней с сохранением покрытия и UV |
| `internal/scene` | Общие типы геометрии и координат |
| `internal/exporter` | Обычная и потоковая запись GLB |
| `internal/service` | Сеанс мира, отмена, кеши и фоновые работы; `http.go` — HTTP-адаптер |
| `frontend/src/main.ts` | Состояние GUI, действия пользователя и получение статуса |
| `frontend/src/ui` | Статическая разметка, SVG-значки и справка |
| `frontend/src/viewport.ts` | Камеры, управление, выделение, координация просмотров |
| `frontend/src/world-tiles.ts` | Очередь запросов 3D и владение декодерами |
| `frontend/src/preview-batches.ts` | Пакетная отрисовка и освобождение GPU-ресурсов |
| `frontend/src/map-tiles.ts` | Независимая 2D-карта и кеш PNG |
| `cmd/package-icon`, `cmd/package-release` | Иконки, архивы выпуска и контрольные суммы |

## Контракты, которые легко нарушить

- Границы выделения включительны. `min == max` означает один блок. Локальная геометрия использует начало `Scene.Origin`; вычитание начала необходимо и для игроков.
- Биомы хранятся на сетке по четыре блока. Для смешивания цветов соседние данные загружаются с запасом; этот запас не должен попасть в экспортируемую геометрию.
- Отсечение граней, оптимизация экспорта и оптимизация просмотра — разные задачи. Цвета, ориентация/фаза UV, прозрачность и нестандартные модели ограничивают объединение граней.
- Тайл просмотра не является экспортом выделения. Его вытеснение, переключение в 2D или лимит памяти не должны менять выходной GLB.
- У каждого запроса есть поколение. После отмены ответ может уже декодироваться; проверяйте поколение перед добавлением в сцену. Старый обработчик `finally` не должен удалить новый запрос с тем же ключом.
- Go-построители имеют собственные изменяемые кеши. Архивы ресурсов можно разделять только в пределах защищённого времени заимствования. Закрытие сервиса сначала отменяет работу, затем дожидается её завершения.
- `ArrayBuffer` передаётся работнику с передачей владения. Обычная GPU-текстура сохраняет `ImageBitmap` до последнего материала; после копирования в слой массива bitmap освобождается. `Texture.dispose()` сам по себе не закрывает bitmap.
- Бюджеты кешей — не предел общей RAM/VRAM. Не выдавайте счётчик буферов за пиковую память процесса.
- Архив выпуска строится во временный файл и публикуется только после успешного закрытия. Контрольная сумма должна соответствовать именно опубликованному ZIP.

## Проверки и оформление

Сначала выполните сборку для своей платформы по README: она создаст встроенные ресурсы и фронтенд. Затем:

```sh
go test ./...
go vet ./...
```

В каталоге `frontend`:

```sh
npm ci
npm run format
npm run format:check
npm test
npm run build
```

Go оформляется через `gofmt`, TypeScript/CSS/HTML — закреплённым Prettier. TypeScript также проверяет неиспользуемые локальные переменные и параметры. Форматирование проверяется в CI. Зависимости обновляйте вместе с lock-файлами и соответствующими лицензиями.

Комментарии в исходниках пишутся на английском: объясняйте ограничения формата, владение памятью и причины решений. Не пересказывайте очевидные строки кода. Для нетривиального исправления добавляйте регрессию, которая проверяет наблюдаемое поведение; удаляя неиспользуемую реализацию, удаляйте её отдельные тесты, сохраняя проверки рабочего пути.

Для геометрии сравнивайте покрытие, UV, оттенки и число объектов. Для производительности записывайте сцену, размер области, ресурсы, прогретость кеша и условия измерения. Проверка запуска на одной платформе не подтверждает остальные.
